Decidi usar a recursividade na remoção porque os métodos de inserir e de percorrer a árvore já estavam feitos assim, então achei melhor manter o mesmo padrão para o código fazer sentido. A maior vantagem que vi na recursividade é que não preciso criar variáveis extras para tentar descobrir ou guardar quem é o nó 'pai' daquele que quero apagar, a própria função, quando volta da recursão, já atualiza as ligações da esquerda ou direita de forma automática. Também separei os três tipos de remoção (nó folha, um filho e dois filhos) em métodos diferentes só para o código ficar mais organizado e fácil de perceber, usando a procura pelo sucessor para resolver o caso de nós com dois filhos sem estragar a ordem da árvore.
